# Схема базы kanji-mirror

Цель: хранить учебную базу кандзи — главы, уроки, символы и фразы с чтениями.

Диалект DDL: **SQLite** (`schema/schema.sql`). Типы и ограничения переносятся на PostgreSQL/MySQL с минимальными правками.

---

## Обзор связей

```
chapter 1──* lesson
lesson  1──* lesson_phrase
kanji   1──* lesson_phrase          (основной символ фразы)
lesson_phrase 1──* phrase_kanji
kanji   1──* phrase_kanji           (все символы во фразе)
lesson.prev_id → lesson.id          (цепочка порядка внутри главы)
```

---

## chapter

Список уроков (уровень / том / курс).

| Поле    | Тип        | Описание                          |
|---------|------------|-----------------------------------|
| `id`    | INTEGER PK | Идентификатор списка              |
| `title` | TEXT       | Заголовок (например `N5`, `N4`)   |

---

## lesson

Урок внутри главы. Порядок задаётся связным списком через `prev_id`
(у первого урока главы `prev_id IS NULL`).

| Поле         | Тип          | Описание                          |
|--------------|--------------|-----------------------------------|
| `id`         | INTEGER PK   | Идентификатор урока               |
| `prev_id`    | INTEGER NULL | Предыдущий урок (`FK → lesson`)   |
| `title`      | TEXT NULL    | Опциональная тема урока           |
| `chapter_id` | INTEGER      | Родительский список (`FK → chapter`) |

**Заметки**

- `prev_id` выбран намеренно вместо `position`: вставка урока в середину — это перестановка двух ссылок, без перенумерации всей главы.
- `prev_id` должен указывать на урок той же главы (приложение / триггер).
- Цена подхода: обход порядка — следование по цепочке (или материализованный порядок в UI), а не `ORDER BY position`.

---

## kanji

Справочник символов. Первичный ключ — сам символ.

| Поле           | Тип      | Описание                |
|----------------|----------|-------------------------|
| `char`         | TEXT PK  | Символ 漢字 (1 grapheme)|
| `on_yomi`      | TEXT NULL| Онные чтения            |
| `kun_yomi`     | TEXT NULL| Кунные чтения           |
| `nanori_yomi`  | TEXT NULL| Именные чтения (名乗り) |

**Заметки**

- Несколько чтений в одном поле: через `・` (или `,`), например `セイ・ショウ`.
- Нормализованная таблица `kanji_reading(kanji, kind, reading)` — возможное улучшение позже.
- `char` хранится как TEXT; уникальность на уровне строки Unicode.

---

## lesson_phrase

Фраза в контексте урока, поясняющая конкретный символ.

| Поле             | Тип        | Описание                                      |
|------------------|------------|-----------------------------------------------|
| `phrase_id`      | INTEGER PK | Идентификатор фразы                           |
| `lesson_id`      | INTEGER    | Урок (`FK → lesson`)                          |
| `kanji`          | TEXT       | Основной символ фразы (`FK → kanji`)          |
| `is_nanori`      | INTEGER    | `1`, если фраза про именное чтение, иначе `0` |
| `phrase`         | TEXT       | Текст фразы / слова с символом                |
| `phrase_reading` | TEXT       | Чтение фразы (кана / латиница — по договорённости) |

**Заметки**

- `kanji` здесь — символ, *ради которого* фраза попала в урок.
- Полный состав символов фразы — в `phrase_kanji` (там же флаг `main`).
- Ожидается согласованность: для фразы есть ровно одна строка `phrase_kanji` с `main = 1`, и её `kanji` совпадает с `lesson_phrase.kanji`.

---

## phrase_kanji

Кандзи, встречающиеся во фразе.

| Поле        | Тип           | Описание                                           |
|-------------|---------------|----------------------------------------------------|
| `phrase_id` | INTEGER       | Фраза (`FK → lesson_phrase`)                       |
| `kanji`     | TEXT          | Символ (`FK → kanji`)                              |
| `main`      | INTEGER       | `1`, если фраза поясняет именно этот символ        |
| `first`     | INTEGER       | `1`, если символ встречается в базе впервые        |

Первичный ключ: `(phrase_id, kanji)`.

**Заметки**

- `first` — «первая встреча» в учебном порядке (по цепочке уроков), а не просто «первый символ во фразе».
- Поддерживать `first` можно при вставке (приложение) или периодическим пересчётом.

---

## Принятые решения

- Порядок уроков: связный список (`prev_id`), чтобы удобно вставлять уроки внутрь главы.
- UI заполнения: нативное приложение на **GPUI** (без браузера / локального веб-сервера).
- Хранение: **SQLite** рядом с приложением.

## Открытые решения (на потом)

1. Формат чтений: одна строка vs отдельная таблица.
2. Нужна ли отдельная сущность `phrase` вне урока (переиспользование фраз).
3. Хранить ли смысл / перевод фразы и кандзи (`meaning`).
