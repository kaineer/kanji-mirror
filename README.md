# kanji-mirror

Инструмент для ведения базы изучаемых 漢字: главы (уровни), уроки, символы и фразы с чтениями.

## Статус

Сейчас зафиксирована только **схема данных**. Приложение и загрузка контента — позже.

## Документация

- [Описание сущностей](docs/schema.md)
- [DDL (SQLite)](schema/schema.sql)

## Сущности (кратко)

| Сущность         | Назначение                                      |
|------------------|-------------------------------------------------|
| `chapter`        | Список уроков (например N5, N4)                 |
| `lesson`         | Урок внутри главы; порядок через `prev_id`      |
| `kanji`          | Символ и его чтения (он / кун / нанori)         |
| `lesson_phrase`  | Фраза в уроке, поясняющая символ                |
| `phrase_kanji`   | Связь фразы со всеми входящими в неё кандзи     |
